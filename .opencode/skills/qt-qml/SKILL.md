# Qt/QML
- Inspect existing QML components before editing.
- Check implicitWidth, implicitHeight, contentWidth, and contentHeight.
- For 32-band EQ controls, verify model count and scrolling behavior.
- Keep sliders synchronized with editable numeric fields.
- Preserve signal handlers and controller bindings.
- Do not assume a C++ controller must have a JavaScript implementation.
